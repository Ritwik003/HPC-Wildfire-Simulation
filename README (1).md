# GPU-Accelerated Wildfire Spread Prediction using CUDA, OpenMP and Real-World Wildfire Data

This project implements a **GPU-accelerated wildfire spread prediction system** using a **2D Cellular Automata (CA)** model. The wildfire simulation is implemented in three versions:

* **Serial C++**
* **OpenMP (CPU Parallelization)**
* **CUDA (GPU Parallelization)**

The project evaluates the simulation using the **Google Research "Next Day Wildfire Spread" dataset** available on Kaggle. Instead of relying solely on synthetic wildfire scenarios, the simulator is validated against **real wildfire observations** using the **Intersection over Union (IoU)** metric.

All three implementations (`serial.cpp`, `openmp_sim.cpp`, and `cuda_sim.cu`) share the same wildfire spread physics and deterministic hash-based random number generator from `common.h`. Using identical simulation logic ensures that all implementations produce consistent wildfire spread results while allowing direct performance comparison between Serial, OpenMP, and CUDA versions.

# Dataset

This project uses the **Next Day Wildfire Spread** dataset published by **Google Research** and available on **Kaggle**.

**Dataset Information**

* **Dataset Name:** Next Day Wildfire Spread
* **Provider:** Google Research
* **Platform:** Kaggle
* **Link:** https://www.kaggle.com/datasets/fantineh/next-day-wildfire-spread

The dataset contains **real satellite-derived wildfire observations** represented as **64 × 64 spatial grids**. Each sample consists of environmental variables together with wildfire masks from consecutive days.

The project primarily uses the following data layers:

* Previous-Day Fire Mask (`PrevFireMask`)
* Next-Day Fire Mask (`FireMask`)
* NDVI (Normalized Difference Vegetation Index)

The **Previous-Day Fire Mask** initializes the wildfire simulation, while the **Next-Day Fire Mask** serves as the ground truth for evaluating the simulation.

# Wildfire Spread Model

The wildfire spread is modeled using a **2D Cellular Automata (CA)** approach.

Each grid cell stores information such as:

* Fuel
* Moisture
* Wind Direction
* Wind Speed
* Fire State

At every simulation step:

* Burning cells ignite neighboring cells.
* Spread probability depends on fuel availability, moisture, wind direction, and distance.
* Burning cells remain active for a configurable number of steps (`burn_time`) before becoming permanently burnt.

The same wildfire spread rules are shared across the Serial, OpenMP, and CUDA implementations to ensure identical simulation behavior.

# Performance Evaluation

Simulation accuracy is evaluated using **Intersection over Union (IoU)**.

IoU measures the overlap between the wildfire mask generated by the simulator and the actual wildfire mask from the dataset.

```
IoU = Intersection(Prediction, Ground Truth)
      --------------------------------------
          Union(Prediction, Ground Truth)
```

Where:

* **Prediction** = wildfire mask generated by the simulator
* **Ground Truth** = actual next-day wildfire mask from the dataset

An IoU value closer to **1.0** indicates better agreement between the simulated wildfire spread and the real wildfire observations.

The project also experiments with different simulation parameters such as:

* Number of simulation steps
* Base ignition probability (`base_rate`)

to identify the configuration producing the highest IoU.

# Build

On the Ramanujan Universe HPC cluster, load the required modules:

```bash
module load cuda
module load gcc
```

Build the project:

```bash
make

# or individually

make serial
make openmp_sim
make cuda_sim
```

If `nvcc` is unavailable, verify the installed CUDA module:

```bash
module avail cuda
which nvcc
```

# Run

```bash
./serial <width> <height> <steps>

./openmp_sim <width> <height> <steps> <num_threads>

./cuda_sim <width> <height> <steps>
```

Example:

```bash
./serial 1000 1000 200

./openmp_sim 1000 1000 200 8

./cuda_sim 1000 1000 200
```

Example output:

```text
[serial] grid=1000x1000 steps=200 time=6532.10 ms burning=1820 burnt=41210

[openmp threads=8] grid=1000x1000 steps=200 time=980.44 ms burning=1820 burnt=41210

[cuda] grid=1000x1000 steps=200 time=42.17 ms burning=1820 burnt=41210
```

The final burning and burnt cell counts should match across all implementations, confirming that the CUDA and OpenMP versions produce results identical to the Serial implementation.

# Simulation Parameters

Simulation parameters are defined in `common.h` (`SimParams`).

Important parameters include:

* `base_rate` – ignition probability
* `wind_x` – wind direction (X-axis)
* `wind_y` – wind direction (Y-axis)
* `burn_time` – number of burning iterations
* `ignite_cx` – initial fire X-coordinate
* `ignite_cy` – initial fire Y-coordinate

These parameters can be modified to simulate different wildfire conditions.
